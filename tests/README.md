# Сквозные проверки пульта

Скрипты запускаются на сервере студии под root (`sudo bash tests/e2e_p0.sh`), поднимают отдельный экземпляр API на тестовой базе и порту 3098/3099, ничего не трогают в боевой базе и удаляют за собой тестовую базу.

- `e2e_p0.sh` — конфиг, версии, откат, режим работы, заявки.
- `e2e_p1.sh` — шаблоны, промокоды, флаги, заметки, метрики, CSV.
- `e2e_pay.sh` — счета и оплата ЮKassa на заглушке.
- `e2e_my.sh` — «Мои заявки» и удаление данных клиентом: чужие заявки недоступны, без подписи отказ.

Запускать после любого изменения `server/studio-api/app.py`.
