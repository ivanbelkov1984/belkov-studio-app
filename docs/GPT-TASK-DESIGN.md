# Задание GPT: дизайн-референс мини-приложения «Студия Белькова»

Дата: 05.11.2026. Заказчик: Иван Бельков. Исполнитель: GPT с навыком UI/UX-дизайна мобильных интерфейсов. Используй свой навык дизайна, но соблюдай правила ниже.

## Что это
Мини-приложение студии внутри Telegram и MAX. Студия делает SMM-продвижение, чат-ботов, мини-приложения и ИИ-ассистентов под ключ для малого бизнеса. Приложение — витрина и воронка: услуги и цены, решения по задачам, кейсы, калькулятор, заявка.

Полное ТЗ (экраны, функции, поведение) — файл `SPEC.md` рядом. Прочитай его целиком.
Образец по структуре (не по визуалу и не по текстам): https://chatlabs.ru/ — каталог услуг по платформам, решения по функциям бизнеса, страницы кейсов «задача → решение → скриншоты → результат», процесс работы.
Текущая рабочая версия (только для понимания контента, не как образец дизайна): https://ivanbelkov1984.github.io/belkov-studio-app/
Пример реального кейса: каталог мотосалона ТРИУМФ — https://t.me/TriumphMoto_bot/catalog

## Что нарисовать
Мобильные экраны 390×844 (iPhone 14), **две темы** — тёмная и светлая (мессенджеры передают тему клиента):
1. Главная (оффер, 3 направления, доверие, мини-кейс, шаги работы, CTA).
2. Услуги — список с фильтрами (направление + площадка).
3. Карточка услуги — описание, что входит, 3 тарифа, интеграции, похожий кейс, CTA.
4. Решения — сетка сценариев по задачам бизнеса (продажи, поддержка, сфера услуг, промо, мероприятия, мото/авто).
5. Кейсы — список + карточка кейса ТРИУМФ (обложка, задача, функции блоками, галерея скриншотов, результат, демо, CTA).
6. Калькулятор — 4 шага и экран итога.
7. Заявка — форма с полями из ТЗ, состоянием ошибки, согласием на ПДн; экран «Заявка отправлена».
8. Компоненты: нижняя навигация (5 вкладок), чипы-фильтры, карточки, кнопки (основная/вторичная/закреплённая снизу), поля, тарифная карточка, бейджи площадок (Telegram, MAX), состояния (нажатие, фокус, неактивно, загрузка, пусто).

## Стиль
- Ощущение: современная продуктовая студия, техничная и дружелюбная, без «корпоративной скуки» и без игрового шума. Премиально, чисто, много воздуха.
- Предложи **2 направления** визуала (A и B). Ориентир: тёмная база + один яркий акцент + один вторичный акцент. В текущей версии: фон #0F1115, поверхность #1A1D24, акцент фиолетовый #7C5CFF, вторичный бирюзовый #24D3A6 — можно улучшить, но обоснуй.
- Шрифты бесплатные с кириллицей: заголовки — Oswald или Unbounded/Manrope (на выбор), текст — Inter.
- Иконки — одна линейная библиотека (Lucide или аналог), без эмодзи.
- Мессенджерный контекст: верхний отступ под шапку Telegram/MAX, нижняя навигация 64 px + safe-area, кнопки ≥ 48 px.
- Обложки кейсов и иллюстраций — реальные скриншоты или нейтральные графические плашки. Никаких фото людей с лицами, выдуманных клиентов, логотипов чужих брендов.

## Обязательные правила
- Доступность WCAG AA: контраст текста ≥ 4.5:1 (крупный ≥ 3:1), видимый фокус, текст ≥ 13 px, цели нажатия ≥ 44 px.
- Не придумывать цифры, награды, отзывы, логотипы клиентов. Где нужно — «Заглушка» и пометка в макете.
- Цены в макете — из ТЗ, с пометкой «от».
- Сетка 4 pt, отступы 16 px по краям.
