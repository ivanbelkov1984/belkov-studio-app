# Акт оценки вреда, который может быть причинён субъектам персональных данных

Основание: ч. 5 ст. 18.1 152-ФЗ; требования приказа Роскомнадзора от 27.10.2022 № 178. Оператор: [ОПЕРАТОР]. Дата оценки: [ДАТА]. Оценку проводит ответственный за организацию обработки ПДн ([ОПЕРАТОР]).

## 1. Методика

Вред оценивается как последствия нарушения требований закона (утечка, потеря, неправомерное использование). Степень вреда — высокая, средняя или низкая — определяется по приказу № 178. Выбрана степень по наиболее тяжёлому последствию.

## 2. Оценка по видам нарушений

| Нарушение | Последствие для субъекта | Степень | Баллы* |
|---|---|---|---|
| Утечка контактных данных (имя, ID, телефон, e-mail) | спам, мошенничество, раздражение, но без прямого финансового ущерба | низкая | 1 |
| Утечка договорных данных (ФИО, паспорт, ИНН, реквизиты) | риск мошенничества и подделки документов | средняя | 5 |
| Утечка данных участника акции (контакт, результат) | раскрытие участия, спам | низкая | 1 |
| Неправомерный отказ в удалении данных | сохранение данных без основания | средняя | 5 |
| Рассылка без согласия | нарушение права на покой, штрафы для Оператора | низкая | 1 |
| Хранение данных на иностранном сервере | нарушение закона, возможные санкции для Оператора; субъектам — риск утечки | средняя | 5 |

*Баллы — внутренняя шкала для сравнения: низкая 1, средняя 5, высокая 10.

## 3. Результат

**Степень вреда: СРЕДНЯЯ** (наиболее тяжёлый случай — утечка договорных данных клиентов-физлиц; при этом количество субъектов небольшое, специальных и биометрических данных нет).

## 4. Соотношение вреда и мер

Принятые меры соразмерны вреду: УЗ-4, шифрование, ограничение доступа, хранение в РФ, минимизация (паспортные данные только для договоров и только после подписания), резервные копии, удаление по срокам, журнал и регламент утечки.

## 5. Пересмотр

При появлении специальных/биометрических данных, расширении числа субъектов более 100 000, новых целях или переносе сервера — повторная оценка.
