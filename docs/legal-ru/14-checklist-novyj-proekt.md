# Чек-лист запуска нового проекта на российском сервере

Пройти по порядку до публичного запуска. Любой проект: бот, мини-приложение, сайт, канал.

## A. Инфраструктура

- [ ] Сервер и база данных в РФ (ч. 5 ст. 18 152-ФЗ). Провайдер указан в Политике.
- [ ] Данные граждан РФ пишутся сначала в базу в РФ; копии в иностранных облаках, таблицах, CRM, почте, AI-сервисах не делаются.
- [ ] HTTPS с действительным сертификатом (для MAX требуется HTTPS и доверенные сертификаты).
- [ ] Вход на сервер по SSH-ключу, пароль отключён, файрвол, автообновления.
- [ ] Резервные копии в РФ; проверка восстановления.
- [ ] Токены ботов и ключи API — только в защищённых переменных, не в репозитории.
- [ ] Платёжные данные не хранятся на своём сервере (платёжный сервис).

## B. Документы

- [ ] Политика опубликована (01), ссылка есть в боте, приложении и подвале сайта.
- [ ] Согласие (02) — отдельная галочка, не предустановлена, ссылка на текст; факт согласия пишется в журнал.
- [ ] Согласие на рекламу (03) — отдельная галочка, если есть рассылки.
- [ ] Приказ (04), Положение (05), перечни (06), оценка вреда (07), уровень защищённости (08), журналы (10), регламент утечки (11).
- [ ] Поручения (12) на хостинг и подрядчиков.
- [ ] Правила розыгрышей (13), если акции.
- [ ] Для мини-приложений и сайтов: описание cookie и метрик в Политике; баннер только если используются не строго необходимые cookie.

## C. Роскомнадзор

- [ ] Уведомление подано до начала обработки (RKN-UVEDOMLENIE.md). Номер записи внесён в журнал.
- [ ] Место хранения базы в уведомлении совпадает с реальным.
- [ ] При любом изменении (цель, состав данных, сервер, подрядчик) уведомление обновлено в течение 10 рабочих дней.
- [ ] Трансграничная передача: нет; если есть — отдельное уведомление и юридическая проверка.
- [ ] Каналы от 10 000 подписчиков: проверить обязанность регистрации в перечне РКН (иначе нельзя размещать рекламу и принимать донаты).

## D. Реклама и контент

- [ ] Платная реклама и реклама чужих товаров маркируются (erid через ОРД, ст. 18.1 38-ФЗ).
- [ ] Рассылки только при согласии (ст. 18 38-ФЗ) и с отпиской.
- [ ] Нет обещаний, которые нельзя подтвердить (цены, наличие, гарантии, результаты).
- [ ] Права на музыку, изображения, шрифты, тексты проверены; для Suno — тариф генерации сохранён в паспорте релиза.
- [ ] Люди на фото, в видео и отзывах — только с согласием на распространение (ст. 10.1 152-ФЗ).
- [ ] AI-визуал помечен как визуализация (в рабочих материалах).

## E. Самозанятость

- [ ] Доход не превышает 2,4 млн ₽ за год; только свои услуги и работы, без перепродажи чужих товаров; без работников по трудовым договорам.
- [ ] Чек «Мой налог» по каждому платежу.
- [ ] Договор и акт на услуги (приложение студии).
- [ ] Рекламный бюджет оплачивает клиент напрямую площадке.

## F. Эксплуатация

- [ ] Внутренний контроль раз в год.
- [ ] Запросы субъектов обрабатываются за 10 рабочих дней.
- [ ] Удаление данных по срокам и по отзыву, акты.
- [ ] Регламент утечки известен, ключи и токены можно отозвать за минуты.
